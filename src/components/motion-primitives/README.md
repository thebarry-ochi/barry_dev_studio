# Motion Primitives

Add selected components here in Phase 1 from https://motion-primitives.com/docs.
Motion Primitives is a copy-in component collection, not a runtime package to install wholesale.
Tailwind v4, Motion, `cn()` and the shadcn-compatible `components.json` are ready.
Review each component's imports and install its specific dependencies when selected.
Keep interactive components behind `"use client"`, preserve upstream attribution,
and use the shared MotionProvider's reduced-motion policy. No animation components
are copied or rendered in Phase 0.
